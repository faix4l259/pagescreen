# Pagescreen

## A color-safe, night-aware PDF reader for Android

**Download:** [Pagescreen v1.1 APK](Pagescreen-v1.1.apk)

Pagescreen is made for calmer long-form PDF reading. It adapts neutral paper and text colors while preserving the original colors of charts, diagrams, photos, and annotations.

### Features

- Read any PDF from your device
- Choose Charcoal, True Black, Midnight Navy, Deep Forest, Espresso Dusk, and more page themes
- Choose custom page and text colors
- Preserve diagram, chart, photo, and annotation colors
- Search for words across the document
- Jump straight to a page
- Zoom in and out with crisp high-density rendering
- Switch between continuous scrolling and single-page reading
- Resume the latest saved PDF at the page where you stopped
- Remove saved PDFs whenever you want
- Works locally: PDFs remain on your device

### Install on Android

1. Download the APK.
2. Open it from Downloads.
3. If Android asks, allow installation from your browser or file manager.
4. Tap **Install** and open Pagescreen.

### Android project

`pagescreen-android` contains the Android source wrapper for the reader.
